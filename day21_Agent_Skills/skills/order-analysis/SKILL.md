# 订单分析 Skill

## 1. 适用场景

当用户需要分析订单数据、统计订单金额、分析订单状态或识别异常订单时使用本 Skill。

## 2. 分析步骤

1. 获取订单数据。
2. 检查订单数据是否包含订单编号、订单金额和订单状态。
3. 统计订单总数和订单总金额。
4. 按订单状态分类统计。
5. 检查金额异常、订单信息缺失等问题。
6. 整理分析结果并输出结论。

## 3. 异常判断规则

- 订单金额小于或等于 0：标记为异常。
- 订单编号缺失：标记为异常。
- 订单状态缺失：标记为异常。
- 不要仅凭订单金额较高就认定订单异常。

## 4. 输出要求

分析结果应包含：

- 订单总数
- 订单总金额
- 各状态订单数量
- 异常订单及异常原因
- 简要分析结论

## 5. 注意事项

- 只能根据实际获取的订单数据进行分析。
- 不允许编造订单数据。
- 如果数据不足，应明确说明缺少哪些信息。
